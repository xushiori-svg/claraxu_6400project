# Clara Xu — Personal Website

My personal website, built with [Quarto](https://quarto.org/) and hosted on
GitHub Pages.

🔗 Live site: https://xushiori-svg.github.io/claraxu_6400project/

## What's here

- `index.qmd` — home page
- `about.qmd` — about me
- `bio.qmd` — bio
- `resume.qmd` — resume
- `blog/` — blog posts (course assignments and other writing)
- `_quarto.yml` — site config
- `docs/` — rendered site output (published by GitHub Pages)

## How to run this locally

1. Install [Quarto](https://quarto.org/docs/get-started/).
2. From the project root:
   ```
   quarto preview
   ```
3. To rebuild the published site:
   ```
   quarto render
   ```
   This updates the `docs/` folder, which GitHub Pages serves.
